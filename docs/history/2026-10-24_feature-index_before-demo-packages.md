# Реестр систем Guild Warehouse

Актуализация 24.10.2026. Фактическая база — d053eef; новое направление — браузерное демо без привязки к монетизации. Таблица отделяет наличие в коде от предложенной следующей работы. Приоритет «срез» — рекомендация для проверки трёх фаз, не разрешение на реализацию всех строк. Владелец задач — TBD; distribution для всех строк — all, применительно к текущему демо.

Обязательное правило новой игры: все здания и рабочие места заранее существуют; игрок приобретает, расчищает, восстанавливает и преображает их через заданные состояния. Строительного редактора нет.

Предыдущий реестр сохранён в [истории](history/2026-10-24_feature-index_before-meta.md).

## Реализованная основа

| feature_id | Система | Статус реализации | Связь с метой / нужная доработка |
| --- | --- | --- | --- |
| item_catalog | 84 вида, 5 категорий | Есть | Ограничить стартовый ассортимент; связать происхождение с подземельем |
| visitor_intake | Мешки, один ожидающий, случайные паузы | Есть | Дать правила закупки и бюджет для работы без хозяина |
| table_sorting | Свободная раскладка и сортировка | Есть | Сохранить ручной режим; различить команду и фоновую работу гнома |
| warehouse_organization | Отдельные вещи, коробки, сохранённые позиции | Есть | Сводки запаса, резервы контрактов и понятный сбыт излишков |
| order_generation | До 4 принятых поручений, гарантии | Есть частично | Развести профессии и повторяемые/особые заказы |
| parcel_assembly | Сборка, частичная посылка, выдача | Есть | Гоблин, резервирование и сохранение ручных посылок |
| item_examination | Изучение одним кликом и очистка | Есть | Повторно использовать жест для шара; сохранить ручные открытия |
| item_collection | Атлас, изучение без расхода экземпляра | Есть | Небольшие тематические открытия вместо выдачи всех семейств сразу |
| warehouse_upgrades | Четыре одноразовые покупки | Есть | Не образуют лестницу автоматизации; новая цепочка отдельна |
| auto_sort | Бесплатная команда, известные предметы | Есть | Фоновая автономия отсутствует; новую роль гнома ещё проверить |
| rewards_and_stats | Деньги, бонусы, итоги | Есть | Перебалансировать источники; добавить чистую прибыль и расходы бизнеса |
| reputation_unlocks | 3 доступных ранга | Частично | Открывать клиентов/контракты/возможности, не только случайный пул |
| save_and_resume | Локальный прогресс, FTUE, позиции | Есть | Новые состояния персонала/бизнеса потребуют проверки совместимости |
| onboarding | FTUE, повторный старт с обучением | Есть | Добавлять короткое обучение при каждой смене роли |
| day_cycle | 5 дней, визуальные периоды суток | Есть | Снять конфликт конечного пятого дня с новой метой |
| input_and_navigation | Клик/перетаскивание, окно/стол, настройки | Есть | Переключение предприятий с непрерывной работой остальных |
| art_audio_text | Фоны, спрайты, аура, базовые звуки | Частично | Запущенная лавка и ремонт отсутствуют; новые звуки пока перспектива |
