# Документация Guild Warehouse

Актуальный срез реализации и оставшихся задач: [аудит проекта от 24.09.2026](project-audit-2026-09-24.md). Приведённая ниже карта от 11 сентября содержит исторические статусы; её расхождения с текущей игрой перечислены в аудите.

Рабочая карта от 11 сентября 2026 года. Основание — концепт v5, аудит и ответы пользователя. Выбрано направление спокойной бесплатной браузерной игры с рекламой для ПК и телефона горизонтально; короткий MVP с одним улучшением и ориентиром на пять игровых дней. Подробные правила уточняются через интервью gd-doc-kickoff. Нерешённые вопросы помечаются TBD, предложения не становятся требованиями без ответа пользователя.

## Правило работы

По запросу пользователя перед дальнейшими изменениями необходимо согласовывать объём. Последний запрос «собери небольшую версию, чтобы сейчас поиграть» разрешил текущую тестовую реализацию. Она находится в dist/; её состав, временные параметры и ограничения описаны в playable-build.md. Исторический v5 сохранён отдельно. Экспериментальные параметры сборки не утверждают спорные правила будущего релиза.
