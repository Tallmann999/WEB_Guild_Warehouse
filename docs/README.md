# Документация Guild Warehouse

Рабочая карта от 11 сентября 2026 года. Основание — концепт v5, аудит и ответы пользователя. Выбрано направление спокойной бесплатной браузерной игры с рекламой для ПК и телефона горизонтально; короткий MVP с одним улучшением и ориентиром на пять игровых дней. Подробные правила уточняются через интервью gd-doc-kickoff. Нерешённые вопросы помечаются TBD, предложения не становятся требованиями без ответа пользователя.

## Правило работы

По запросу пользователя перед реализацией любых изменений необходимо задать вопросы и получить согласование конкретного объёма. Подготовка документации и обсуждение разрешены. На этом этапе игровой код не меняется. Исправления, рекомендованные аудитом, также требуют согласования перед реализацией.
