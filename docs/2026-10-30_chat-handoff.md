## Сохраняемые правила игры

- Локальный Phaser4.2.1, обычный JavaScript без сборки/CDN; один canvas и кадровый цикл. Симуляция вне сцен, DOM для UI и переднего высыпающего мешка/Борина. Для Phaser читать `docs/development-skills/phaser-2d-game/SKILL.md`.
- День1: касса80, мешки10, посылки40/60; уборка30 после первого дня. День2: шесть поставок и две обычные выдачи. Оба утренних преображения по4 активные секунды.
- Борин: найм120, сортировка2,5сек/предмет, комиссия2 за партию один раз.
- Грик: новое предложение послеB2 при кассе≥800 без привязки к дню, цена найма240. Уже показанное/отклонённое предложение сохраняет доступ; после отказа постоянное напоминание. Найм включает помощника и сохраняет ручные резервы.
- Сборка Грика2сек/вещь, выдача3сек, комиссия3 один раз. При включённой автоматизации сам выдаёт порученные посылки и на стойке. Частичный dispatch.elapsed переживает загрузку/паузу/переходы.
- Кухня необязательна и параллельна. Кухня/алхимик: по6 вещей за200, три выдачи, сГриком197. Алхимик после покупки башни. День5 оружейная:5мечей+5кинжалов+5шлемов за360, три выдачи, сГриком357. Обычная посылка90/87. Исторические выплаты не пересчитываются.

- Работа разрешённых сотрудников продолжается за книгами/распознаванием/картой/башней. Пауза/настройки/скрытая вкладка/сюжетные решения/ремонт останавливают соответствующие активные часы; офлайн-дохода нет.
