# Склад гильдии — играбельный прототип

Откройте `index.html` в корне проекта или `dist/index.html`. Установка пакетов и сборка не нужны. Текущий локальный просмотр: http://127.0.0.1:18765 (пока запущен сервер). На телефоне нужен доступный телефону хостинг/локальный сервер; этот адрес доступен только на текущем компьютере.

## Что можно попробовать

- Пять игровых дней, покупка мешков с неизвестным содержимым и торговые заказы.
- Свободная сортировка мышью или касанием, подсказка категории после ошибки.
- Заказ с ингредиентом из следующего поступления; список справа над столом.
- Покупка «Диковинок», уборка остатка мешка одним действием и раскладка между двумя коробками.
- Очистка находки и запись изображения в коллекцию; товар остаётся доступным для заказа.
- Три доступных ранга из семи, новые виды вещей в дальнейших закупках.
- Пауза, звук, тестовая рекламная автосортировка и локальное сохранение.

## Управление

Купите мешок у стойки. Перетащите вещь в коробку либо нажмите вещь, затем коробку. Нажатие пустой рукой на коробку открывает её. Для заказа откройте список и отправляйте подходящие экземпляры из коробок в посылку. Закройте коробку перед выдачей. «Улучшение» позволяет купить временное хранилище; «Коллекция» — очистить находку. Escape закрывает осмотр или окно. При завершении всех приходов у стойки появляется «Закончить день».

## Временные правила этой сборки

Это реализация для немедленного теста по запросу пользователя, а не утверждение всех открытых решений дизайна. Баланс: 80 стартовых монет, мешок 10, улучшение 20, заказ 20–28. День: 180 секунд у стойки, на рабочих экранах часы идут вдвое медленнее. Планируется 3–4 закупки в день. Кнопка ожидания позволяет ускорить пустые промежутки. Ожидающие авантюристы остаются доступными после вечернего закрытия новых приходов.

Перенос ещё обсуждается: при закрытии с незавершённым заказом можно явно выбрать уменьшение выплаты до 80% либо сохранение базовой суммы. Во втором варианте отдельный бонус своевременности ещё не реализован. Повторные переносы не уменьшают сумму вновь. Эти кнопки предназначены для сравнения на тесте, не для финального интерфейса. Сборка берёт только рассортированные вещи; прямую выдачу из «Диковинок» пока нельзя проверить. В конце пятого дня — итоги, просмотр склада или новая игра.

Сохранение привязано к браузеру и адресу запуска. Запуск из файла и через локальный сервер используют разные хранилища. Настоящие рекламные SDK, интеграция портала, бонусы наборов коллекции и разделка монстров не подключены. Сенсорные действия проверяются эмуляцией, физический телефон ещё нужен для плейтеста. Реальная длительность 15–30 минут — гипотеза, не результат пользовательского теста.
