# Таверна у подземелья

Версия 0.1.0 · 11 сентября 2026 года · зафиксированный концепт игрового прототипа.

Этот документ закрепляет концепт и решения, принятые при работе над прототипом Monster Tavern Tycoon. Текущая версия служит отправной точкой для отдельного репозитория. Работоспособность основного цикла проверена; интерес игроков и долгосрочный баланс ещё предстоит проверить на плейтестах.

## Фантазия игрока

Игрок — хозяин таверны рядом с опасным подземельем. Для авантюристов это место, где можно поесть, пополнить припасы и превратить добычу в полезные ресурсы. Постепенно маленькая таверна становится важным местом для героев.

## Формат

Браузерный 2D tycoon с автоматическим обслуживанием и короткими ручными заданиями. Целевая сессия исходного концепта — 5–20 минут. Основная платформа прототипа — компьютер, горизонтальное окно, мышь; предусмотрена адаптация под узкое окно и обработка указателя для касаний.

Зал расположен сверху в одной видимой сцене. Персонажи и мебель используют предоставленные объёмные иллюстрации. Это сочетание плана таверны сверху и фронтальных/трёхчетвертных изображений объектов; строгая единая перспектива пока не выстроена.

## Основной цикл

Гости приходят и занимают столы. Персонал автоматически выполняет простые заказы. Особые заказы требуют действий хозяина: приготовить блюдо, собрать припасы или разобрать трофей. Обслуживание приносит золото и репутацию. Игрок покупает улучшения, увеличивает вместимость и скорость работы, открывает рецепты и принимает следующие заказы.

Наблюдение за движением гостей и ростом таверны чередуется с осмысленными короткими действиями. Улучшения должны давать видимый результат в помещении и понятный эффект в экономике.

## Закреплённые решения

| Область | Решение текущей версии |
|---|---|
| Рабочее окно | На широком экране карта и управление помещаются в окно без прокрутки страницы |
| Особые заказы | Крупные светлые карточки справа с названием, временем ожидания и наградой |
| Журнал | Блок «У очага» удалён из интерфейса |
| Склад и рецепты | Компактные кнопки по центру нижней части сцены; каждая открывает отдельное окно |
| Сбор предметов | Перетаскивание с полки в зону заказа; альтернативно взять кликом и положить кликом |
| Подсказка состава | Иконка, название и количество находятся непосредственно в целевой ячейке |
| Готовка | Положить ингредиенты на плиту → нажать «Готовить» → дождаться заполнения полоски → автоматическая подача |
| Точность готовки | Ловля бегунка и отдельная кнопка подачи отменены |
| Трофей | В этой версии остаются три надреза с попаданием в зелёную зону |
| Арт | Используются изображения из всех восьми пользовательских листов; Kenney исключён из действующей сборки |
| Доставка результата | Самостоятельный HTML для игры и исходники для дальнейшей разработки |

Эти решения относятся к принятой версии прототипа. Возврат к прежней готовке, мелким тёмным карточкам или вкладкам склада в нижней панели будет изменением концепта текущего взаимодействия.

## Объём текущей версии

Одна таверна с залом, кухней и кладовой; три стартовых стола с расширением до шести; три типа заказчиков с десятью внешностями; два сотрудника; восемь рецептов; двенадцать ингредиентов; три ручных задания; пять веток улучшений по три уровня; повторяемый пир после рейда; три последовательные цели; локальное сохранение.

## Дальнейшее направление

Исходный концепт предполагает развитие таверны в приключенческий хаб: новые биомы и комнаты, более редкие гости, дополнительные профессии, рецепты из монстров и разнообразные события. Эти идеи сохраняются как направление развития. Они не входят в реализованный объём версии 0.1.0 и не являются утверждённым планом ближайших работ.
